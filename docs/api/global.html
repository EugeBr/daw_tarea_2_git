calcularPrecioFinal() → {void}

Calcula el precio final aplicando el IVA seleccionado. Obtiene el precio introducido por el usuario, valida que no sea negativo y muestra el resultado con dos decimales. Si se produce un error durante el proceso, muestra el mensaje correspondiente en el elemento de resultado. Devuelve el precio con desglose.
